纯 Rust 端侧 LLM 引擎

tinymodel 用同一份 Rust stable 代码库覆盖 Raspberry Pi Zero 2W（≤0.5B）、手机与 ARM 开发板（≤5B）及主机 GPU（≤8B 及 26B 循环 MoE）。直接 mmap 加载 GGUF，一等支持 Qwen3.5 GDN、Gemma 4 PLE、LFM2 与端侧 QLoRA 微调。
