tinymodel 用同一份 Rust stable 代码库覆盖 Raspberry Pi Zero 2W（≤0.5B）、手机与 ARM 开发板（≤5B）及 Apple / AMD / NVIDIA 主机 GPU（稠密 ≤9B 与 26B–120B 稀疏 MoE）。零拷贝加载单/多分片 GGUF 与 .strata 容器，一等支持 Qwen3.5/3.6 GDN+MTP、Gemma 4 PLE、Mamba-2、多模态视觉及端侧 QLoRA 微调。

First-Class Architectures

全谱系小模型、四大前沿 MoE、多模态与端侧微调

不走动态计算图，每个模型结构手写零堆分配 forward、多步投机验证图捕获与独立激活重算 QLoRA 反向。

System Architecture

为端侧带宽红线与 GPU 极致吞吐而生的分层设计

严格隔离 unsafe 边界（仅限内核、GPU 后端、FFI 与 mmap），在生成 token 热路径上实现零堆分配。
