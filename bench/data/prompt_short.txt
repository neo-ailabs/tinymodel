 Autoregressive language model inference divides cleanly into two hardware-distinct phases: prompt processing (prefill) and token generation (decode). During prefill, the engine evaluates all input tokens simultaneously, turning weight projections into matrix-matrix multiplications (GEMM) with high arithmetic intensity. On modern edge processors, prefill is compute-bound and benefits directly from wide SIMD or matrix extensions such as ARM dotprod, I8MM, SME2, x86 AVX-512 VNNI, or GPU tensor cores. In contrast, single-stream decode evaluates one token per step, reducing projections to matrix-vector multiplications (GEMV) where every weight parameter is fetched from DRAM for just two floating-point operations. Consequently, decode throughput approaches the ratio of sustained memory bandwidth to model byte size. Optimizing an on-device runtime therefore requires a dual strategy: maximizing tile reuse during prefill while minimizing bytes read per generated token through quantization, layout repacking, selective vocabulary projection, and speculative multi-token verification. Hybrid architectures such as Gated DeltaNet and short-convolution blocks further reshape the memory profile by replacing growing key-value caches with fixed-size recurrent states that must be carefully checkpointed across conversation turns and rolled back cleanly on rejected draft tokens. Measuring both micro-benchmarks and end-to-end deterministic greedy completions under a frozen corpus provides a rigorous baseline against which every subsequent kernel or runtime change can be validated without regression.
