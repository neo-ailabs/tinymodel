# 路线图（Roadmap）

> 每个阶段都有可量化的验收标准。基线以同一台机器上的 llama.cpp 为准（见 `TESTING.md` 的基准协议）。

| 阶段 | 内容 | 验收标准 | 状态 |
|---|---|---|---|
| **M0 基线** | 在 M4 和 Pi 5 上用 llama.cpp 测量基准模型集的 pp、tg、内存峰值、温度和频率 | 有可复现的基线表格，存入 `bench/baselines/` | 🟡 M4 已完成（2026-11-19），Pi 5 待测 |
| **PoC** | ① 用 Rust 写 Q4_0×Q8_0 GEMV（NEON dotprod + i8mm `asm!`），以 `Strata/src/quant/arm/arm_dots.inc` 为蓝本；② 交叉编译 aarch64-musl，在 Pi 5 和 Zero 2W 上运行；③ objc2-metal 量化 GEMV；④ 内核对齐和 bench 测试框架 | ① 在 M4 上 ≥95% ggml；② 二进制 <2MB，Pi 5 带宽利用率 ≥80%；③ ≥90% llama.cpp Metal | 🟡 M4 + **Google Pixel 8 真机验证通过**（2026-11-20：877KB 静态 `aarch64-musl` 在 Tensor G3 真机通过 L1 自检，`Llama-1B` 带宽利用率 **90.9%**，`SmolLM2` 达 **83.6–90.0 tok/s**），Pi 5 / Zero 2W 待跑 |
| **M1 最小可用** | Cargo workspace 骨架；tm-core / tm-gguf（张量表校验）/ tm-cpu（generic + NEON + dotprod + AVX2）/ 线程池；Llama + Qwen3 的 forward；tokenizer；采样；CLI `run` / `bench` | 贪心解码输出和 llama.cpp 逐 token 一致；Pi 5 decode ≥95% llama.cpp | 🟡 M4 上 Llama/Qwen3 + 采样器 + NEON F16 KV / 4×8 `smmla` 完成（2026-11-20：SmolLM2 `pp512=588.8 / tg128=270.5 tok/s` [= **106.3%** llama.cpp `--no-repack` / **116.1%** 默认]，Llama-1B `pp512=246.6 / tg128=84.9 tok/s` [= **96.4%** llama.cpp]，micro 静态二进制 668KB），Pi 5 实测待跑 |
| **M2 新结构 + Metal** | Qwen3.5（GDN，按 `GDN_CONTRACT` 实现）、Gemma 4（PLE、滑动窗口）、LFM2；LayerState；前缀缓存；**Metal 后端** | 多 token logits 的 KL 低于阈值；M4 Metal decode ≥90% llama.cpp Metal | 🟡 **Qwen3.5 GDN（CPU NEON 向量化 + Metal）+ LayerState + Q5_K + Metal 零拷贝/FlashAttention 已完成**（2026-11-21：Qwen3.5-0.8B Metal `pp512=1551.7 / tg128=127.0 tok/s` [= **99.3%–100.8%** llama.cpp Metal]；M4 CPU 4T `pp512=406.8 / tg64=127.8 tok/s` [= **118.5%** llama.cpp]；**Google Pixel 8 真机 5 轮随机交错配对比率反超 `llama.cpp --repack 0`**：`Qwen3.5-0.8B` `pp512=101.2% / tg64=101.5%`、`Qwen3.5-2B` `pp512=108.5% / tg64=96.5%`，真实脏内存仅 `43.5–44.9 MiB`）；Gemma 4 / LFM2 / 前缀缓存待做 |
| **M3 性能** | prefill GEMM 微内核；suffix 和 MTP 投机解码 + 按收益选择；多 token 共享权重；LM head 优化；KV 量化；**Vulkan 后端**（覆盖 AMD、Intel 显卡、Mali、Pi 5 VideoCore） | Pi 5 prefill ≥1.5× llama.cpp，有效 decode ≥1.3× | 🟡 **异构大小核自动绑核（`affinity.rs`）+ Prefill 非矩阵算子并行化（GDN Conv1d/Recurrence、SwiGLU、批量 GQA）已完成**（2026-11-21：Pixel 8 免 `taskset` 开箱提速 **3.3×–5.0×**，`Llama-3.2-1B` Prefill 达 **106.9%** `llama.cpp --repack 0`）；`Q4_0_4x8` 离线重排 / 投机解码待做；**Vulkan（ADR-010，AMD 优先）**：V0 基线 + Mesa 25.2.8 ✅、V1 Q4_0 GEMV ✅、V2 Llama/Qwen3 Decode Runner ✅、V3 CoopMat Prefill + FlashAttention ✅、**V4 Qwen3.5 GDN ✅**（2026-11-21：`Qwen35VkRunner` + 寄存器/LDS 驻留 GDN 递推 + 并行 Conv1d + 向量化 `Q5_K`/`Q6_K` GEMV，RADV/ANV/lavapipe 三驱动 + FP64 oracle + `logits_diff` 100%/92% Top-1 通过；RX 9060 XT 5 轮中位数 `pp512 / tg128`：**Qwen3.5-0.8B `13567 / 366.5 tok/s` [= `164.5% / 149.2%` Vk，`116.3% / 217.8%` HIP 全线反超！]**、**Qwen3.5-2B `5206 / 184.5 tok/s` [= `108.3% / 182.7%` Vk，`69.1%` 墙钟（GPU 热态 `102.7%`）/ `137.4%` HIP]**），下一步 V5 跨设备实测 |
| **M4 micro 档** | ARMv8.0 NEON 和 TBL 查表内核；低比特格式（IQ2/3、Q2_0、三值）；词表裁剪；零拷贝 | Zero 2W 上 SmolLM2-360M Q4 ≥5 tok/s，内存 ≤350MB | 🟡 **ARMv8.0 NEON 全套量化内核（Q4_0/Q4_1/Q8_0/Q5_K/Q6_K）+ GGUF 零拷贝词表 + 扁平 Tokenizer + Linux cgroup v2 内存探测已完成**（2026-11-20：SmolLM2-360M `Isa::NeonV80` 提速 **+44.3%**、脏内存仅 **25.3 MiB** / 总 RSS **248 MiB**；Qwen3.5-0.8B 脏内存省 **87.2 MiB** 至 **51.8 MiB**；`micro` 纯静态 ELF **745KB** 零 `sdot`/`smmla`）；低比特格式 / TBL 待做 |
